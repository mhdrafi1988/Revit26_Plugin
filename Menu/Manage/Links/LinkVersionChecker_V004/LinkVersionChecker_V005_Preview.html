V005 proposal — new Sync column + ACC-only filter. Assumptions flagged for approval.
  • Verified against the Revit 2026 API docs: ExternalResourceReference.GetResourceVersionStatus() returns ResourceVersionStatus = Current / OutOfDate / Unknown, and .Version gives the version string last loaded. That is the real "is it synced" answer — not a guess.
  • On-demand, not automatic. The cost of that call is undocumented (it may hit the network per link), so it runs from the Check cloud status button in the footer with progress + Cancel. Press it below to see the dots resolve. Scans stay fast and work offline.
  • Pure ACC links can only be checked In-Model. Pre-Open and Folder Audit read the host .rvt from disk — no Revit session, no sign-in, no live reference to ask. Switch tabs: those rows go Not in this mode instead of pretending.
  • Desktop Connector is different — it works in all three modes. "Downloaded vs not downloaded yet" is read from Windows file attributes (RECALL_ON_DATA_ACCESS / OFFLINE / reparse point), no API and no sign-in needed. Assumption: Autodesk does not document DC's placeholder behaviour — if the attributes aren't there on your PC it degrades to "Not checked" rather than lying. Your first run tells us.
  • Assumption: OneDrive / SharePoint rows get the same downloaded dot, since the detection is identical. Say the word if you'd rather leave non-ACC rows blank.
  • ACC links only tick box = the existing SourceGroup.Acc (ACC this project, ACC other project, BIM 360 legacy, and Desktop Connector) and it overrides every other filter — Source, Type, Problems, Upgrade needed, Host and the search box all grey out while it is on.
  • Assumption: two new rules feed the existing Findings / severity / estimate / Excel machinery for free — ACC_OUT_OF_DATE (Warning) and ACC_NOT_DOWNLOADED (Warning, adds download seconds to the open estimate). Watch the Check column and the cards change when the status resolves.
  • Confirm the glyphs: filled ● = you have the current bits · hollow ◯ green = it is in ACC but not on this PC yet · dashed ◌ grey = unknown / not asked. Try — tell me which you want in the grid.
  • Metrics card is now 9 tiles (two new, outlined). Say if you'd rather drop one to keep it at 7.
