# Malayalam Writing Project

A workspace for writing researched Malayalam pieces: you give a seed idea, Claude expands it paragraph by paragraph in Malayalam, backed by historical, scientific, and other factual research with references.

## Structure

- `PROMPT.md` — the reusable instruction prompt describing the workflow. Load this at the start of a writing session.
- `topics/` — one Markdown file per piece (`topics/<slug>.md`), each with the seed idea, the Malayalam draft, and a references section.
- `topics/_template.md` — copy this when starting a new topic.

## How to use

1. Give an idea in English or Malayalam (a topic, line, or theme).
2. Claude researches supporting history/science/facts and drafts the piece in Malayalam, paragraph by paragraph.
3. Review, revise, or redirect any paragraph — treat drafts as living documents.
4. References accumulate at the bottom of each topic file.
