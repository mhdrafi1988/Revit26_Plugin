Vertex Data Run Summary
Sheet 1
Vertex Data

Every roof vertex — processed and skipped — with its nearest drain, path length and calculated elevation offset. Optional ElevModel_mm / ElevDiff_mm columns appear when Verify after commit is on, flagging anything Revit silently adjusted.

Sheet 2
Run Summary

Parameter/value table for the whole run — slope, thresholds, drain counts, timing — one row per setting, ready to paste into a submittal log.

Multi-roof
Combined Summary

When "Combined summary" is on, one extra workbook compares every roof in the batch — longest path, highest elevation, drain count — alongside each roof's own file.
