Element count per workset — each workset header shows the sum of all its elements before you expand it, so you can gauge scope at a glance without opening every node.
Starts collapsed — the tree opens compact; expand only the worksets you need. "Expand All" and "Collapse All" buttons are always available in the toolbar.

Three-state checkboxes

Checking a workset or category cascades down to every type beneath it. Checking or unchecking an individual type bubbles back up — the parent shows indeterminate when only some children are checked.
Cascade down
Check a workset → every category and type inside is checked automatically.
Bubble up
Uncheck one type → its category goes indeterminate; uncheck all → it goes unchecked.
Live count
The status strip updates instantly: types checked · total element count.

3D view workflow

Two paths to the same result — type row click or toolbar button — both land in a view you choose.
One type, one click
Click a type's underlined name or its Show in 3D row button → confirm → pick a 3D view → isolate + select that type's elements.
Any mix of types
Check across worksets and categories, then hit Show Checked in 3D → pick a view → all checked elements in one shot.
